Инструкция

Инструкция по запуску Unlock Sniper в Termux

1. Установите Termux

Скачайте и установите Termux.

2. Обновите пакеты

pkg update && pkg upgrade -y

3. Установите Python и пакеты

pkg install python git nano -y
pip install requests ntplib

4. Запуск скрипта

cd /sdcard/UnlockSniper
python main.py
